# NoYtDelhi

Restore the pre-2025 youtube controls

<img width="1333" height="78" alt="image" src="https://github.com/user-attachments/assets/b229e704-bac9-4724-8e70-a0033eafdc51" />

Unlike [OldYTPlayer](https://greasyfork.org/en/scripts/553368-oldytplayer-youtube-old-player-ui-pre-2025-minimal-tweaks), 
it doesn't rely on feature flags that are likely to break in the future. Just DOM/CSS changes.


It also doesn't come with extra features like SponsorBlock or Return Youtube Dislike.
Those provided by OldYTPlayer are not as good as the original versions and cause problems
with said originals, so they're just useless.

If you have a userscript injector, [click here](https://github.com/Gameknight963/NoYtDelhi/raw/refs/heads/master/NoYtDelhi.user.js)
to install it.
